> **A website similar to travel booking sites features several interactive buttons and photos showcasing different types of vacations.**

## Implemented features:
- Ability to sort offers by different parameters (adventure, cruise, etc.)
  
- Elements that stand out / highlight on hover

- Links leading to different parts/elements of the site

## Technologies
- Python

- JavaScript

- HTML/CSS

## How to Run
- Download or clone the repository
- Open "index.html" in your browser
